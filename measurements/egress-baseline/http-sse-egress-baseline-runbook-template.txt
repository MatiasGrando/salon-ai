HTTP EXPORT PRIVACY
- Process the HTTP export locally and retain only totalDuration and deploymentInstanceId.
- Never retain raw path, user agent, IP, host, request ID or unrelated provider fields.

STOP AND ROLLBACK
- Stop on functional impact, malformed/rejected records, sustained/immediate safety breach, overflow/drop/gap, or unavailable required source.
- First redeploy with affected flags false. Wait bounded recovery evidence.
- Full application rollback only when disabling telemetry does not restore behavior, cannot be made safe, or pre-approved severity requires it.
- No migrations exist for this change.

PRIVACY AND RETENTION
- Restrict exports and record retention/access authority above.
- Never retain raw URL/query/body, headers, cookies, auth, PII, tenant/customer identifiers, provider payloads, errors/stacks, or media paths.

SSE PROCESS-CRASH CAVEAT
- Un crash del proceso puede omitir el contador `closed` y la duración final de una conexión SSE activa.
- Esa ausencia no debe interpretarse como conexión entregada, activa globalmente ni finalización exitosa.
